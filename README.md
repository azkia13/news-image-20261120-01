Satu gambar yang merangkum berita dunia Jumat 20 November 2026 — halaman depan koran yang digambar dari nol. Lead: serangan terbesar Rusia ke Kyiv (400+ drone, 110+ misil, tiga jembatan Dnipro kena, 8 tewas) yang meluber ke Polandia (2 misil + 1 drone). Tujuh tile lain: Trump tunda keputusan perang Iran sampai 2027 + Senat blokir 51–48; misil Houthi menghantam menara PIF Riyadh; IPO Anthropic +17% tapi pasar anjlok (S&P −2%, Nikkei −4,8%); KTT EU–UK di Brussels; putusan ICJ Myanmar genosida Rohingya 9–6; Kenya bebas Ebola; GTA VI $2,3 miliar. Plus kotak "by the numbers" dan strip "also today" (COP31, IMF, denda Meta €805 juta, FAA ground stop, Bukele).

Gambar PNG 1024×1024 digambar deterministik oleh draw_front.py (Python + Pillow, tanpa network, tanpa randomness) dari cerita yang dilaporkan 20 November 2026, diverifikasi terhadap Reuters, AP, WSJ, CNN, BBC, Just Security dan Euronews. main.py (Python 3.13, stdlib saja) menyalin entry.png ke output directory, sama seperti starter kit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
python3 draw_front.py
```
